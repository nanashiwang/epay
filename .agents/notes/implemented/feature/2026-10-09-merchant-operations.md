# Agent Note: 包月商户运营与部署闭环

Status: implemented

## Problem

商户直收和包月权益已有独立凭证，但旧按日返现、首页及 Docker 启动仍沿用代收假设。已付款套餐冲突缺少管理员处理入口，关闭购买还会隐藏历史，订阅到期缺少提醒。

## Existing capabilities and impact

[商户通道](../../implemented/architecture/2026-10-09-merchant-payment-channels.md)、[订阅](../../implemented/architecture/2026-10-09-bepusdt-merchant-subscription.md)、[收款监测](../../implemented/feature/2026-10-09-merchant-collection.md)部分重叠，保留原支付验证、用户组与到期事实来源；帮助中心仅同步操作说明。原生码匹配和能力审查笔记无关，没有应删除或拒绝的旧提案。

## Decision

- 按订单持久凭证排除商户自助直收、测试和新订阅订单的按日返现，不依赖商户后来切换的套餐。旧代收返现保留。
- 复用订阅事件，另存管理员处置审计；处理已付款冲突需会话、CSRF、理由及当前权益快照。开通不同套餐需明确确认替换，按处理时起算已购月数；同套餐从原有效期累加。线下处理只登记凭证，不转账或自动退款。
- 我的套餐始终可读；首页按当前订阅身份展示业务订单、权益与配置状态。测试不算业务收入，既有代收视图保留。
- 站内提醒实时计算；邮件复用现有会员通知开关，在到期前 7/3/1 天及到期后登记去重与失败重试，不自动扣款。任务失败不阻断收款监测。
- Docker 使用站点外持久卷，更新脚本在重建前保全旧容器密钥，缺失/冲突时停止更新；独立监督 worker，未迁移时安静等待。不自动对生产迁移。

## Runtime findings

无证书启动的旧 sed 删除留下未闭合的 server 块，且原配置在 Compose 中只读；实际 `nginx -t` 失败。现在每次启动从只读模板生成完整可写配置，再执行语法检查。Docker 忽略规则原先排除 docker 配置与所有 Markdown，现允许构建配置和帮助文章进入镜像。

## Alternatives considered

- 根据当前用户组排除返现：简单，但切换套餐后会改变历史订单含义，改用订单凭证。
- 自动覆盖冲突套餐或自动退余额：操作少，但隐式决定已付权益价值，改为管理员明确处置和不可重复审计。
- 只补 Docker 文档：不改变启动，但容器重建仍可能丢失密钥；补保全过程并拒绝静默生成替代密钥。
- 新建订阅系统：可自由定价，代价是两套有效期和账务；沿用已有表及小范围扩展。

## Verification

隔离 PHP 8.3 / MySQL 8 验证返现筛选、处置权限/CSRF、重复/并发/过期快照和审计回滚、提醒去重/失败重试及续期重置，42 项运营检查通过。通道 106、BEpusdt 136、原生码 80、收款账号 73 项回归通过。浏览器在实际 PHP 页面与合成账号上验收桌面、390px、深色媒体样式（fixture 强制加载）、关闭购买后历史、处置成功/空态、迁移缺失错误及刷新恢复、字段帮助和账号进度。Docker 构建、旧密文重建后解密、权限、冲突/缺失拒绝、SSL 两种状态与重启验证通过；完整运行环境显式迁移后 worker 以 www-data 自动启动，登录页面 HTTP 200。新增 Merchant Operations CI 持续执行 MySQL 与容器测试；生产、真实邮件和付款仍未验收。

## Consequences

管理员替换套餐会影响剩余权益，必须显示前后差异；邮件发送与数据库不能成为同一事务，崩溃可能重复投递，按至少一次设计。旧密钥必须在旧容器销毁前保全，外部自定义路径由旧容器环境变量确定，复制到新持久卷；独立备份仍由运维负责。上线、真实邮件与付款另行验收。

提醒执行边界由[进程隔离](../architecture/2026-10-09-worker-isolation.md)扩展：邮件独立进程、每轮配置刷新和完成心跳；原提醒账本不变。

[订单保留](../bug-fix/2026-10-09-order-retention.md)补足历史清理入口，保留订阅与收款审计引用的主订单。

[开通指南](2026-10-09-merchant-onboarding.md)补齐未开通商户入口，沿用权益和通知数据。

[订阅看板](2026-10-09-subscription-dashboard.md)复用付款与权益记录，并明确余额与外部支付的统计口径。

[支付异常核对](2026-10-09-payment-review.md)补充查单证据和审计，保留原付款确认边界。

[更新验收](../process/2026-10-09-update-verification.md)消费任务心跳并核对当前容器标识、迁移及历史密文，失败不显示更新成功。
