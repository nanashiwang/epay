# Agent Note: 商户帮助中心与外部文档适配

Status: implemented

## Problem

商户可以自配支付通道，但现有开发文档主要描述 API，仓库中的运行说明也不适合普通商户直接操作。用户提供支付FM文档，希望收集其中的教程并形成站内帮助。

## Existing capabilities and impact

- 复用 `index.php?doc=`、`Template::loadDoc` 与现有 `/doc/*.html` 入口，不引入另一套站点或数据库。保留已有 API 文档及各模板入口。
- [自配通道](../../implemented/architecture/2026-10-09-merchant-payment-channels.md)、[BEpusdt](../../implemented/architecture/2026-10-09-bepusdt-merchant-subscription.md)和[原生码](../../implemented/feature/2026-10-09-merchant-collection.md)笔记部分相关：作为功能事实来源，帮助文档不扩展支付权限。
- 原站存在专有 API、额度费、监测软件、轮询池和人工补单，与本项目包月、固定金额、默认账号和凭证确认不同。未找到明确的全文再分发许可；保存可追溯目录和适用性，编写基于本项目代码的教程，不把原站整篇、截图或下载程序嵌入发布内容。
- 能力审查流程与原生码匹配笔记不被替代，没有重复的帮助中心决定。

## Decision

帮助中心是公开、只读的文档页面，提供分类、全文搜索、文章目录与相邻导航。内容用仓库 Markdown 和显式目录维护，PHP 渲染限定的标题、段落、列表、表格、代码及链接；不执行原始 HTML，不按查询参数拼接任意文件路径，不引入运行依赖。用户中心、通道配置页、套餐页和 API 文档可进入帮助。

收集原站目录内全部公开页面，记录 URL、标题、核对日期、正文指纹、获取结果、本地对应教程及适用范围；来源仅用于参考，不自动同步覆盖本地操作说明。原站平台特有或本项目未开放内容保留参考链接并明确标注。

## Alternatives considered

- 原文镜像：保留最多原信息，但没有明确再分发授权，且会把其他平台的收费、接口和按钮当成本站能力。
- 只放外部链接：维护成本低，但不能指导本站套餐、自配通道与故障处理；采用本地原创教程加来源索引。
- 新建文档站或引入 Markdown 框架：渲染能力完整，但增加构建或运行依赖；本次采用受限格式、复用 PHP 文档入口。

## Verification

- 原站目录 97 个唯一页面均通过 HTTPS 获取，保存获取结果与正文指纹；本地提供 22 篇适配教程。
- `php tests/help-center.php` 通过 724 项检查，覆盖目录、来源映射、本地链接、搜索、HTML/URL 转义、路径与数组参数拒绝、400/404 和现有入口。PHP/JS/Python 语法与笔记结构检查通过。
- 浏览器在本地 PHP 预览中通过匿名阅读、中文多词搜索、无结果、无效文章、刷新、API 文档和商户导航入口；390×844 窄屏及深色表格无页面横向溢出。商户导航使用真实模板和模拟身份，未接触生产数据。
- 新增独立 Help Center CI，不依赖原站联网；原有支付回归工作流保持原状。
- 相邻 API 文档验收发现原有目录在相对 URL 匹配失败时引用未定义的 `currentCatalog`。改为按当前路径或 `doc` 参数选择节点，复验章节切换与帮助入口正常。

## Consequences

商户可以在本站按实际入口操作，管理员也有套餐教程；仓库内 Markdown 便于审阅，渲染无需额外 PHP 或前端依赖。公开页面不改变支付权限，不读取商户配置。受限 Markdown 放弃复杂嵌套与原始 HTML，换取明确的输出边界。

外部后台和产品会变化，原站文档不构成本站功能承诺。`scripts/check-help-sources.py` 只读比较来源指纹，发现变化后人工复核，不自动覆盖本地教程。维护者需同步目录和文章，敏感配置或真实凭据不能进入文档。生产部署与文档提交分开。
