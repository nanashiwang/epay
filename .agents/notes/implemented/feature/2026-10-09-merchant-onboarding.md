# Agent Note: 新商户开通引导

Status: implemented

## Problem

未购买套餐的新商户仍落入旧结算资料门槛，已有工作台只对已分配套餐显示，用户看不到完整开通路径。

## Decision

复用套餐、通道测试、默认路由和通知证据，增加可反复查看的开通指南。已启用自助收款的站点中，默认组、未填结算资料且没有历史业务单的商户首页进入指南。既有商户仍可主动打开指南，不自动迁移权益或支付资格。

## Related notes

[包月运营](2026-10-09-merchant-operations.md)部分重叠：复用工作台样式并补未开通入口；[通道架构](../architecture/2026-10-09-merchant-payment-channels.md)的测试和租户边界不变。

## Alternatives considered

- 对所有商户直接改套餐：入口统一但改变既有签约和收款路由，缺少迁移授权与数据依据。
- 仅添加帮助链接：成本低，但新用户仍先被要求填写无关结算资料。

## Testing

12 项 MySQL 与实际页面测试通过；浏览器验证桌面、390px 深色、暂停购买、禁用账号拦截及刷新恢复。进度必须由实际记录计算，保存账号不等于收款验收。

## Consequences

默认组有历史业务单的商户不会自动跳转，需从侧栏进入；指南不代替真实付款与业务通知测试。

原生码 verified_at 仅证明账单接口校验，不计为测试到账；指南单独显示原生码接口进度并要求收款验收。通用和 USDT 通道的到账测试继续以 tested_at 为据。
