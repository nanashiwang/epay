# Agent Note: 包月订阅运营看板

Status: implemented

## Problem

旧后台统计业务代收流水，不能区分套餐成交、余额支付与外部支付，也无法快速识别到期商户和套餐付款异常。

## Decision

独立只读运营入口复用订阅购买、订单、权益事件与当前套餐。时间段按付款时间过滤，最多 366 天。展示套餐成交额、余额消费、外部支付确认额、续购笔数、当前有效/到期人数和异常，按日、套餐汇总及分页到期名单。管理员认证前不查询或输出运营数据。

## Related notes

[包月运营](2026-10-09-merchant-operations.md)部分重叠：扩展只读经营统计，沿用处置队列；其他笔记不改变。

## Alternatives considered

- 用业务流水当月费收入：改动少，但混入商户直收金额及测试。
- 直接称 MRR：易理解，但预付周期、续购、余额抵扣和退款不支持可靠会计口径，故只展示明确订单口径。

## Testing

13 项 MySQL 检查通过，合成订单核对付款时间、余额/外部支付区分、续购、退款排除、日期输入、管理员权限与分页；浏览器验收日期错误、分页、空态、390px 深色及桌面布局。

## Consequences

外部支付确认额不是支付机构结算到账证明，线下退款不自动冲减；权益现状与日期筛选的成交统计分别标注。
