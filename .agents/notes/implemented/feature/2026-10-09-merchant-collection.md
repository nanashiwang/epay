# Agent Note: 商户自助收款账号与到账核对

Status: implemented

后续扩展：[包月商户自配支付通道](../architecture/2026-10-09-merchant-payment-channels.md)为通用套餐引入共享限额、到期权限与零按笔费；本笔记的旧套餐收费路径保留兼容，原生码匹配与监测理由仍成立。

## Problem

商户目前只能由管理员配置子通道，无法在用户中心完成收款码、密钥校验、监测和到账核对。用户要求对齐已查看的 502 商家账单账号管理形式，第一批覆盖实际收款链路和可追溯记录。

## Existing capabilities and impact

- `pre_subchannel` 已有商户归属，`Channel::getSub` 和原生码插件可复用；`mode=1` 已实现本金直收、平台仅扣服务费。
- [原生码笔记](2026-10-09-alipay-native-qr.md) 的金额、时间与歧义限制继续成立。
- `processOrder`、资金明细和易支付签名回调保留；现有监测没有持久化健康状态或未匹配账单，回调没有逐次记录。
- 新页面、专属 API 和扩展表承载商户自助账号；已有管理员通道与商户默认路由不自动改变。生产有独立页面定制，只发布逐文件核对过的差异。

## Decision

复用子通道标识，增加账号扩展表、商户默认选择、收入流水及操作/通知日志。专用父通道保持关闭，避免进入全站随机池；只有明确选择自助账号的商户使用这一入口，失败不回退到平台收款。管理接口依据会话 UID 和 CSRF 校验，密钥在站点目录外独立密钥加密，查询不返回密钥。二维码解析复用项目已有解码器。

一个常驻监测进程读取动态账号配置，保存最近查询/成功时间和失败分类；停用后继续确认尚在窗口内的订单。流水先持久化，再按原生码规则匹配；同金额收银台占用防止并发展示。保留异常与核对备注，不提供无证据的“一键已付”。

到账、原有直收费用账务和流水认领在同一事务中完成；网络回调在提交后处理，沿用易支付签名和重试计划。对新的自助账号提供逐次通知状态、HTTP 状态与耗时，不保存签名查询串或下游原始敏感响应。

操作教程与来源适配见[商户帮助中心](2026-10-09-merchant-help-center.md)；该文档入口不改变本篇的支付和权限边界。

## Alternatives considered

- 完全新增支付引擎可独立演进，但会重复订单、费率、签名及资金明细契约，首批扩展已有引擎。
- 将商户密钥直接放入原有子通道 JSON 改动少，但后台会原样回显，选择独立加密扩展并保留子通道身份。
- 每账号创建 systemd 服务有隔离优势，但商户操作依赖系统权限；首批用动态账号监测器并提供健康状态。
- 自动加价可提高同额并发，但改变客户应付金额。首批保留原额并拒绝冲突，金额递增和轮询池后续单独设计。

## Verification

- 73 项真实 MySQL 隔离集成检查及原有 80 项原生码检查通过。覆盖商户所有权、CSRF、密钥不回显、并发同额占用、流水重放、费用明细写入失败时订单/余额/流水全部回滚、直收本金不入余额、原有签名通知和失败重试。新增独立 MySQL CI；测试订单接口覆盖非自增主键插入成功时 insert 返回 0 的兼容情况及重复点击复用。
- 浏览器验收账号卡片、另一商户空态、流水和通知列表、手机宽度、缺失密钥反馈；用户提供的二维码图片通过原有解码器正确解析。修复快速切换记录页时旧响应覆盖新页及按钮作用错误的问题。
- 生产数据库及逐文件内容已备份，保留生产主题额外样式引用。CLI 新增停用的直收模板、独立加密文件和监测服务；导入既有企业账号并真实校验账单接口。支付宝空账单成功响应会省略 detail_list，已根据真实响应字段补齐兼容测试，服务恢复在线。
- 默认路由没有切换，既有通道状态保留。新商户链路的实付订单与独立业务站通知仍需明确验收，不用历史旧通道测试或模拟签名断言替代。

## Consequences

静态码不能证明付款来自哪个站点，仍需专用收款账号；接口可查账不证明二维码对应同一账号，必须核对付款收款方并实测。独立加密密钥需要与数据库分开备份。单进程首批适合少量账号，规模化需分片与限速。迁移新增表不删除旧数据；回滚需先取消新路由并确认在途订单。通知采用至少一次语义，业务站仍需按订单幂等。

首批原额收款按 13 分钟保守占用避免歧义；不包含金额递增、商户轮询池、细分账号限额或无凭证人工置为已付。原有平台通道配置不自动迁移或删除，新的密钥保护适用于自助账号扩展表。

运营补充见[包月商户运营与部署闭环](2026-10-09-merchant-operations.md)：部分重叠，扩展历史返现排除、异常套餐审计、提醒与持久化部署，保留本篇支付与租户隔离规则。
