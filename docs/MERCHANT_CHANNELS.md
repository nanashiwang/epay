# 商户包月与自配支付通道

商户在 `/user/channels.php` 配置自己的收款账号，支付本金直接进入该账号；平台收取包月软件使用费。管理员管理套餐价格、周期、账号数量、支付类型和用户权限，只为平台自身的会员费、充值等配置平台收款通道。管理员无需为每个商户录入密钥。

## 支持范围

| 入口 | 可用收款方式 | 商户配置 |
|---|---|---|
| 支付通道：支付宝官方 | RSA2 公钥模式，当面付扫码、电脑网站、手机网站 | APPID、卖家 UID、应用私钥、支付宝公钥；选择已签约产品 |
| 支付通道：微信 V3 | 微信支付公钥模式，Native 扫码 / H5 | AppID、商户号、APIv3 密钥、商户证书序列号、商户 API 私钥、微信支付公钥 ID 和公钥 |
| 支付通道：微信 V2 | Native 扫码 / H5 | AppID、商户号、APIv2 密钥 |
| 支付通道：QQ 钱包 | 扫码 / H5 | 商户号、API 密钥 |
| 支付通道：易支付兼容网关 | 跳转网关收银台；支付宝、微信、QQ、银行、京东 | 公网 HTTPS 地址、商户 ID、密钥；按支付类型分别配置 |
| 支付宝收款码 | 原生码与账单匹配 | 见 [原生码配置](MERCHANT_COLLECTION.md) |
| USDT / BEpusdt | CNY 订单、USDT / TRC20 | 商户自己的网关地址与 Token，见 [BEpusdt 配置](BEPUSDT_SUBSCRIPTION.md) |

这里的官方接口需要商户自行完成对应产品签约。微信 V3 密钥加密保存在数据库，调用时在内存中加载，不依赖管理员上传共享文件。服务商进件、JSAPI/小程序共享绑定、证书文件模式及其他历史插件尚未开放；API 客户端使用 `web` 或 `jump` 收款方式。退款由商户在自己的支付机构后台处理，不开放通用转账或自动退款。

## 部署与套餐设置

保留 PHP/MySQL 和现有部署脚本。升级代码不会自动迁移数据库、启用套餐或部署 BEpusdt 服务。部署前备份数据库和站点外加密文件，在站点 PHP 环境依次执行；前两项已经安装时可以跳过：

```sh
php scripts/collection-setup.php --apply
php scripts/bepusdt-setup.php --apply
php scripts/merchant-channel-setup.php --apply
```

最后一项创建五张 `merchant_channel_*` 扩展表和不含凭据、保持停用的系统模板，启用商户配置入口。重复执行不会复制模板。系统模板不是平台收款账号，不能从管理端启用、修改或删除。若后来新增重复名称的支付类型，可重跑脚本补齐对应模板。

沿用 `EPAY_COLLECTION_KEY_FILE`：32 字节主密钥，位于 Web 根目录外，PHP 服务和 CLI 均可读；容器必须持久化挂载。账号与订单快照使用 AES-256-GCM，绑定商户 UID 和用途。数据库与主密钥分开备份；不能直接更换主密钥文件，否则旧密文无法解密。

管理员在“用户组”编辑页开启“商户自配支付通道”，设置 1–20 个账号、套餐售价、可见范围和月数。普通包月设为 1 个月。新通用权益字段为 `merchant_channels_enabled`、`merchant_channels_accounts`；原 `bepusdt_enabled` 套餐仍可单独使用，旧套餐不会自动切换。支付类型的全局停用和用户组关闭规则继续生效。

平台自己的收月费商户由 `reg_pay_uid` 指定，使用管理员配置的平台收款通道。商户自收凭证不能购买平台订阅或给平台余额充值。续期沿用自然月、并发累加与订单幂等事务，付款、权益变更及有效期可在“我的套餐”追溯。当前是预付续期，不自动扣款或发送续费提醒。

## 商户操作

1. 进入“支付通道”，新增接入方式和自己的配置。密钥保存后不回显，编辑时留空保留。
2. 创建 0.01–100 元测试订单，由商户打开收银台并主动付款；收到有效支付回调才标记测试通过。保存成功本身不代表能够收款。
3. 启用并设为该支付方式的默认账号。支付宝原生码与通用支付宝账号互斥默认；微信、QQ、USDT 等各自独立。
4. 在“支付订单”“通知记录”“操作记录”核对收款与业务通知。配置变化会清除测试状态，需要停用后修改并重新验收；归档保留历史记录。

通用套餐中的支付宝、微信、QQ、易支付、原生码及 BEpusdt 共享账号上限，未归档的停用账号仍占名额。降级导致启用数超额时暂停新直收订单，需停用多余账号；新增账号需先归档闲置配置。

通用套餐所有自配收款均不收按笔平台服务费，包括比例费、最低费、随机加价和订单邀请返利；支付机构自身费率由商户签约决定。本金不进入平台余额。不设默认、停用、到期、超限、支付类型关闭均停止对应新收款，不会改用平台账号。套餐到期保留原套餐身份，不自动降为默认用户组；查看历史、停用、取消默认、归档和通知重试仍可使用。

## 回调、运维和回滚

每笔新订单在调用插件前保存加密配置快照。回调先由原 SDK 验签，再核对收款账号身份、支付状态、订单和精确金额；确认到账、流水去重、测试状态及审计在同一事务提交。停用、归档、到期或密钥轮换后，在途订单仍使用原快照；旧测试回调不能验收新密钥。前端返回页不能将订单标为已付。

业务站异步通知复用 `collection-worker.php` 与已有重试记录，不需要另一套 worker。通知按至少一次投递，业务站应按订单号幂等。通用官方接口依赖支付机构回调；没有新增自动查单补单或强制标付入口，丢失回调时需要核对支付机构订单。BEpusdt 创建结果未知等专属处理仍见其文档。

回滚前停止新收款，并保留当前回调代码、扩展表、加密主密钥和通知 worker，直到在途订单完成。不要清空配置表或删除历史快照。账号配置和管理接口不会返回明文密钥；不要把生产凭据写入日志、测试或版本库。
