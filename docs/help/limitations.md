# 原站教程与本站功能有哪些区别

本帮助中心参考支付FM公开目录，并按本站已实现的功能编写操作步骤。本站不是支付FM的镜像；原站的账号、定价、下载软件和接口参数不能直接用于本站。

## 对照表

| 原站主题 | 本站情况 | 建议阅读 |
| --- | --- | --- |
| 接口额度、充值优惠 | 通用模式按套餐周期收费 | [套餐](plans.md) |
| 商户添加收款账号 | 支持已审查的官方接口、网关和专属入口 | [选择支付方式](choose.md) |
| 多账号轮询池 | 自助套餐每种方式一个默认账号 | [订单与账号](orders.md) |
| 收款码金额浮动 | 包月自配订单不随机加价；原生码拒绝同额冲突 | [原生码](native_qr.md) |
| 安卓通知栏、PC 微信监测 | 未接入通用自助模式 | [原站资料索引](sources.md) |

| 发票、客服、服务协议和授权域名 | 适用各自平台，不能套用 | [原站资料索引](sources.md) |

## 原站资料如何使用

所有已获取页面的标题、链接、核对时间、内容指纹及对应本地教程记录在来源清单。原站公开页面全文用于资料核对，没有将整篇原文、截图、视频或软件下载包作为本站内容再分发。

本地操作步骤优先以本站代码和实际页面为准。支付机构后台可能更新，请在机构官方页面确认产品、资质、域名和安全要求；帮助文档不替代机构审核。

## 更新方式

外部目录不自动覆盖本站手册。维护者检查来源变化后，需要同时核对代码、表单、权限和支付流程，再更新本地教程及核对日期。
