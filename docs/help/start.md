# 第一次使用：从开通到收到第一笔款

本手册适用于本站的商户包月、自配通道模式。你向平台购买软件使用期，顾客向你配置的支付账户付款。支付宝、微信或网关的密钥由你在商户后台填写。

## 开始前准备

- 一个本站商户账号，以及可用的包月套餐。
- 一个支持的收款账户及已开通的支付产品。
- 需要收款的业务网站；如果使用现成程序，先确认它支持易支付接口。

## 按顺序完成

1. 打开[我的套餐](/user/groupbuy.php)，购买或续期允许自配通道的套餐，确认有效期。
2. 阅读[支付方式选择](choose.md)，确定使用官方接口、支付宝原生码还是独立网关。
3. 打开[支付通道](/user/channels.php)，选择接入方式，填写自己的参数并保存。
4. 创建测试订单，由你主动完成付款，刷新后台确认到账；按页面要求启用并设为默认。
5. 将本站提供的接口地址、商户编号及 API 凭据填入业务网站，详见[网站与插件接入](integration.md)。
6. 从业务网站下单，核对支付机构、本站订单和业务网站三处结果，详见[完整验收](testing.md)。

## 这三个结果要分开看

“保存成功”表示配置已存储；“测试到账”表示一笔测试凭证通过验证；业务网站发货还依赖它接收并校验本站的支付通知。只看到浏览器跳回成功页，不能确认业务系统已完成入账。

## 从工作台检查准备情况

包月商户首页显示今日业务收款、可用支付方式、通知积压和套餐账号用量，并给出配置步骤。今日业务收款只统计已付款业务订单，测试、充值和套餐付款不计入。账号卡片显示保存、测试、启用与默认四步进度；配置表单提供对应支付方式的帮助链接。

## 查看开通进度

登录后可从“开通收款指南”检查套餐、账号配置、测试和业务通知进度。新商户无需先填写旧结算账户；请使用自己签约的支付账号。保存配置后，仍需完成测试、启用、默认路由和业务网站验收。

原生码的接口校验与收款测试分别验收；接口能查询账单，不代表已经确认测试付款。开通指南会单独标注这两种进度。
