# 配置支付宝原生收款码

入口：[支付宝收款码](/user/collection.php)。本方式通过支付宝收入账单确认付款，需要原生收款码与具备查询能力的应用；本站不要求安装原站的安卓通知监听软件。

## 准备和保存

1. 准备实际收款账号的支付宝 UID、原生收款码，以及对应账单应用的 APPID。
2. 准备应用私钥和支付宝公钥，先核对[密钥用途](alipay_keys.md)。
3. 添加收款账号，填写参数并按页面上传二维码图片或填写原生码地址。原生码地址应为 HTTPS 的 qr.alipay.com 地址。
4. 保存后点击“校验接口”，通过后启用监测，等待页面显示在线。
5. 创建测试收款，按收银台展示的准确金额付款，再核对到账流水并设为默认。

“校验接口”只证明账单查询能工作，不能证明二维码的收款人正确。付款前确认实际收款方，测试后再核对机构账单与本站记录。

## 监测与金额限制

监测进程由本站管理员统一维护。你添加账号后不需要自己创建服务器进程；持续离线时请联系管理员核对 worker 和心跳。

同一账号的相同金额可能已有待确认订单，本站会拒绝冲突，不会偷偷改变应付金额。不要让同一个收款码在多个网站并行接收无法区分的转账。

收银台付款窗口为 5 分钟，后台查询另留有宽限；迟到、金额不符或歧义流水需要人工核对。不要重复付款或直接把业务订单改成已支付。到账流水中的核对说明不等于确认订单成功。

## 修改与退款

修改密钥前需要停用账号，并满足页面提示的在途订单限制。收款 UID 和二维码不能直接替换成另一个收款方。退款由商户在支付宝核对后处理，本站账面状态不代表实际转账。
