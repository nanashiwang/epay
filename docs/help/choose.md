# 选择适合自己的支付方式

先确认你已经具备哪些账户和产品权限，再选择接入方式。拥有账户不代表已经开通该账户下所有支付产品；本站的通道测试也不会替你完成机构签约。

## 当前自助入口

| 已有条件 | 本站接入方式 | 可用场景 |
| --- | --- | --- |
| 支付宝应用与已签约产品 | 支付宝官方支付 | 当面付扫码、电脑网站、手机网站 |
| 微信商户号及 V3 参数 | 微信官方支付 V3 | Native 扫码、H5；微信支付公钥模式 |
| 可使用 APIv2 的微信商户号 | 微信官方支付 V2 | Native 扫码、H5 |
| QQ 钱包商户号和 API 密钥 | QQ 钱包官方支付 | 扫码、H5 |
| 易支付兼容网关账户 | 易支付兼容网关 | 跳转对方收银台，按支付类型分别配置 |
| 支付宝原生码及账单查询应用 | 支付宝收款码 | 固定二维码与收入账单匹配 |
| 自己部署的 BEpusdt 实例 | USDT / BEpusdt | 人民币订单，USDT / TRC20 付款 |

## 按顾客的使用场景选择

桌面网站可选择已开通的扫码或电脑网站产品；手机浏览器可选择已开通的手机网站或 H5 产品。微信内打开网页与普通手机浏览器不同，不要把 Native 或 H5 当成公众号 JSAPI 接口。

本次通用自助配置尚不开放公众号 JSAPI、小程序、服务商进件、共享证书文件和通用代付。即使旧版开发文档或原站文档列出这些接口，也不能据此认为当前套餐已经开放。

## 原生码与官方动态订单的区别

支付宝原生码依靠账单匹配，不是每笔订单生成一张机构动态码。相同金额并发、迟到付款和其他网站共用收款账户可能产生歧义。先阅读[原生码约束](native_qr.md)，再决定是否适合自己的业务。
