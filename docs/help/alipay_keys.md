# 分清支付宝公钥、应用公钥与私钥

支付宝配置经常出错的原因是把三种密钥混用。本站 API 凭据还属于第四套身份，不能混在支付宝字段中。

## 三种密钥的去向

| 名称 | 来源与用途 | 填在哪里 |
| --- | --- | --- |
| 应用私钥 | 你生成并保管，用于应用签名 | 本站支付宝通道的“应用私钥” |
| 应用公钥 | 与应用私钥一起生成，用于支付宝验证应用签名 | 支付宝开放平台对应应用的加签设置 |
| 支付宝公钥 | 支付宝提供，用于验证支付宝返回数据 | 本站通道的“支付宝公钥” |

## 操作顺序

1. 使用支付宝官方提供的密钥工具或组织已有的可靠密钥管理流程，准备至少 2048 位 RSA 密钥对，采用 RSA2。
2. 在[支付宝开放平台](https://open.alipay.com/)打开正确的应用，配置配套的应用公钥。
3. 获取该应用对应的支付宝公钥。
4. 回本站填写 APPID、卖家 UID、应用私钥及支付宝公钥，保存并执行测试。

请通过支付宝官方入口获取工具，不向不明“在线生成器”提交生产私钥。私钥、公钥不能靠名称猜测，应核对其来源以及是否属于同一应用。

## 更换密钥

本站保存后不回显密钥；编辑留空保留原值。计划更换时先停用账号，在机构后台与本站协调完成变更，再重新测试。本站为历史订单保留旧快照，但机构是否仍接受旧密钥由机构规则决定，因此不要把轮换当成没有影响的日常操作。
