# 收款故障排查

先确定问题发生在哪一段：无法创建订单、无法付款、机构到账但本站未确认、本站确认但业务网站未处理。不要把所有问题都归为“回调失败”。

## 无可用支付方式

1. 在“我的套餐”确认通用自配权益有效。
2. 确认对应支付方式已经添加账号，而不是只配置了另一种支付方式。
3. 确认账号已完成测试、已启用并设为默认。
4. 检查启用账号总数是否超过降级后的套餐限额。
5. 如果仍不可用，联系管理员检查支付类型是否关闭、套餐是否允许，以及通道金额和开放时间限制。

未配置或到期时不会自动使用管理员账户收款。新增后只保存、不设置默认，也不能让业务订单自动选中它。

## 配置或签名错误

支付宝先核对 APPID、卖家 UID，以及应用私钥与支付宝公钥。微信先区分 APIv2/APIv3，再核对商户号、AppID、公钥 ID 与证书序列号。外部易支付网关要使用上游给你的商户信息。

修改密钥需要停用后保存，再重新测试。编辑表单中的密钥为空是正常保护行为，不表示密钥丢失。

## 机构已到账，本站仍待确认

- 官方接口：检查机构通知是否到达本站，保留机构流水和本站订单号。
- 原生码：检查监测在线状态、金额、付款时间以及是否存在同额歧义。
- BEpusdt：核对网络、地址、精确币额、网关状态和链上交易号。

不要重复付款，不要仅凭截图修改业务订单。本站没有通用“无凭证标付”入口；需要管理员结合实际凭证处理。

## 本站已到账，业务网站没发货

查看“通知记录”。先修复通知地址、证书、验签、金额校验或 success 响应，再重试通知。业务网站要能处理重复通知，详见[回调验签](callbacks.md)。

## 页面读取失败或配置未生效

刷新页面查看最终保存状态；请求超时不代表一定没有保存。出现初始化提示时联系管理员执行迁移。新功能代码已升级但数据库尚未迁移，也不能视为功能已开通。

## 反馈问题时提供

本站订单号、发生时间、使用入口、脱敏报错、机构是否到账、本站是否已付以及通知结果。不要提供登录密码、私钥、Token、钱包助记词或完整请求签名。
