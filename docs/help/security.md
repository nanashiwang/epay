# 密钥管理与账号维护

本站有两层不同凭据：支付通道凭据用于访问你的收款机构；本站 API 凭据用于让业务网站向本站下单。两层凭据不要混填或共用。

## 日常配置

- 只在自己的商户后台填写收款密钥，不把私钥贴到客服聊天、截图、工单或源码仓库。
- 保存后不回显密钥。编辑时留空表示保留，重新填入表示修改。
- 启用中的通用账号先停用再编辑；修改后需要重新测试。
- 不需要为收款测试提供钱包助记词或钱包私钥。

## 切换默认收款账户

先新增并测试新账号，再启用并切换默认。旧账号可以停用，但应保留历史订单记录。归档前先取消它的默认状态；新账号会占用一个套餐名额。

本站为历史订单保存配置快照，旧测试回调不能用来证明新配置可用。计划在机构后台轮换密钥时，也要考虑机构对旧密钥和在途请求的处理规则。

## 如果怀疑凭据泄露

暂停受影响的新收款并联系本站管理员及支付机构，核对账户活动和在途订单。按机构流程轮换凭据后，更新本站并重新验收。不要仅删除浏览器记录就认为泄露已经处理。

## 管理员需要维护的内容

账号密文依赖站点外主密钥；应与数据库分开备份并持久化挂载。直接替换或丢失主密钥会使历史密文无法解密。具体运行步骤见仓库部署文档，不在商户页面展示密钥文件。
