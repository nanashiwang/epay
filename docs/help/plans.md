# 套餐购买、续期与账号数量

在[我的套餐](/user/groupbuy.php)查看当前套餐、有效期及可购买的产品。售价和允许配置的账号数量由本站管理员设置，请以页面显示为准。

## 购买与续期

1. 选择套餐，确认单次周期、数量和应付金额。
2. 选择页面提供的支付方式；如果允许余额支付，确认余额足够。
3. 付款后回到“我的套餐”，查看付款及权益记录、原到期时间和新到期时间。

周期按自然月计算：仍在有效期内时从原到期时间顺延，已到期时从实际开通时间起算。月末遇到目标月份没有对应日期时，取该月最后一天。当前采用预付续期，不自动扣款。

## 账号总数怎么计算

通用套餐下，支付宝官方、微信、QQ、易支付兼容网关、支付宝收款码及 BEpusdt 合计占用套餐名额。停用但未归档的账号仍占名额；归档可释放名额，历史记录保留。

每种支付方式可以设置一个默认账号。支付宝原生码与支付宝官方接口共用支付宝的默认选择，切换其中一个会替代另一个。账号多不表示自动轮询收款。

## 到期、降级或切换

- 到期后停止新的自助收款，仍可查看历史、停用、取消默认、归档和重试业务通知。
- 在途订单按原凭据继续验证，不因到期或密钥修改丢失原配置。
- 降级后启用账号超出限额时，先停用多余账号；新增账号前可能还需要归档闲置账号。
- 有效套餐切换不自动折算剩余价值。如付款期间套餐被变更，出现待管理员处理提示时，保留付款订单号联系管理员。

## 费用说明

通用包月自配订单不收按笔平台服务费，也不追加最低手续费或随机加价。支付机构自己的交易费用仍按你与机构的约定执行。顾客支付本金直接进入你的收款账户，不增加本站可提现余额。
