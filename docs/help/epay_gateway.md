# 接入你自己的易支付兼容网关

这一入口用于把外部网关作为你的收款上游。若要让业务网站向本站下单，请看[网站与插件接入](integration.md)，两处配置的方向相反。

## 配置上游

1. 在外部网关取得你自己的接口地址、商户 ID 和密钥。
2. 打开[支付通道](/user/channels.php)，选择“易支付兼容网关”。
3. 选择本站支付方式：支付宝、微信、QQ、银行卡或京东；只选上游实际支持的方式。
4. 填写公网 HTTPS 网关地址、上游商户 ID 和密钥，保存后测试。
5. 确认本站收到成功回调，再启用并设为该支付方式默认。

网关地址填写对方提供的接口根地址，不是收银台订单链接。当前地址校验允许 HTTPS 443/8443，不接受本机或内网地址。此模式跳转上游收银台付款，不开放任意上游服务端接口调用。

## 同一上游支持多个支付方式

按支付类型分别添加配置、测试和选择默认。例如支付宝和微信各占一个账号名额，即使两者使用同一上游商户 ID。

## 需要核对的三件事

- 上游能生成真实可支付订单，并把资金计入你的上游账户。
- 上游能发送与本站协议匹配的签名通知，包含正确的商户、支付方式、订单、金额和成功状态。
- 本站确认到账后，你的业务网站能接收本站通知并更新订单。

上游收银台显示成功不代表这三步都完成。上游费用、退款及结算由你与上游约定，本站包月权益不替代这些约定。
