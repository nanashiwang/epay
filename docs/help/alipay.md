# 配置支付宝官方支付

入口：[支付通道](/user/channels.php) → 添加支付通道 → 支付宝官方支付。当前使用 RSA2 公钥模式。

## 参数填写对照

| 字段 | 应填写的内容 | 常见错误 |
| --- | --- | --- |
| 应用 APPID | 支付宝应用编号，20 开头的 16 位数字 | 填成应用名称或卖家 UID |
| 卖家支付宝 UID | 实际收款账号的 2088 开头 16 位编号 | 使用本站商户编号 |
| 支付宝公钥 | 支付宝为该应用提供的验签公钥 | 错填应用公钥 |
| 应用私钥 | 与上传到支付宝的应用公钥配对的私钥 | 换了公钥但保留另一套私钥 |
| 已签约的收款产品 | 实际开通的当面付、电脑网站或手机网站 | 勾选尚未签约的产品 |

## 配置步骤

1. 在[支付宝开放平台](https://open.alipay.com/)确认应用信息及加签方式；在[支付宝商家平台](https://b.alipay.com/)核对已开通产品。
2. 按[密钥对照说明](alipay_keys.md)准备参数，确认应用与实际收款账号的关系正确。
3. 在本站填写通道名称和以上字段，选择实际已签约的产品后保存。
4. 点击“测试收款”，付款后回本站刷新，确认出现测试到账时间。
5. 启用通道并设为支付宝默认，再从业务网站执行一次[完整验收](testing.md)。

## 遇到错误时

签名错误先核对三种密钥的用途和对应 APPID。产品未开通时检查所选产品及机构审核状态。支付页面可打开但本站没有到账记录时，按[通知排查](callbacks.md)区分机构回调与业务通知。

修改配置前先停用；编辑时密钥留空表示保留，填写新值会重新要求测试。退款在自己的支付宝后台处理。
