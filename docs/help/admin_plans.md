# 管理员：创建包月套餐

套餐沿用后台用户组能力，分两处设置：用户组设置定义权益，用户组购买定义售价与上架。商户购买后自己配置收款凭据，管理员不用逐户录入。

## 第一步：设置权益

1. 打开后台“用户组设置”，新增或编辑一个用户组。
2. 设置容易理解的套餐名称。
3. 将“商户自配通道”设为“包月自助：商户配置自己的支付通道”。
4. 设置“自助账号总数”，范围 1–20，支付宝原生码和 BEpusdt 也计入总数。
5. 核对各支付方式的开放状态。下方选择“关闭”仍会禁止该方式；通用自助模式下其余通道选项只表示开放，不指定平台收款人。

## 第二步：定价并上架

1. 打开后台“用户组购买”，开启购买功能。
2. 将目标用户组设为可购买，填写售价和有效期（月）。普通包月设为 1 个月。
3. 设置排序和可见范围。确认准备购买的商户所属用户组在可见范围内。
4. 在商户“我的套餐”中检查实际展示的价格、周期、权益和可购买状态。

通用自助套餐支持 1–120 个月周期，不使用永久期。管理员可以建立多个名称、价格和账号上限不同的套餐；代码不预设收费标准。

## 平台如何收月费

平台月费使用管理员配置的平台收款商户与通道，相关商户由 reg_pay_uid 指定。商户自己的收款账号不能作为平台已经收到月费或充值的凭证。

## 旧套餐处理

已有套餐不会自动变成通用自助套餐。原 BEpusdt 专属权益保留兼容；需要通用能力时主动开启新权益并核对展示。不要仅修改名称就认为商户已获得自配权限。

到期后保留原套餐身份并暂停新自助收款，续期重新获得有效期；不会自动回落到平台收款账户。当前没有自动扣款或续费提醒。
