# 退款、金额异常与投诉处理

通用自配通道的款项进入你自己的机构账户。退款应由你在相应支付机构或上游网关核对并处理，本站当前不通过通用自配接口代发退款。

## 退款前核对

1. 找到业务订单、本站订单和机构流水，确认三者属于同一笔交易。
2. 确认实际到账金额、此前退款记录和商品交付情况。
3. 在机构官方后台按其流程处理，保存退款流水和处理时间。
4. 在自己的业务系统记录结果，避免重复退款或重复交付。

本站或业务网站显示“退款”字样，不等于机构已经转出资金。开发文档中的历史退款接口不表示通用自配通道已开放该能力。

## 少付、多付、迟到付款

支付宝原生码和链上付款都需要准确匹配凭证。金额不一致或超出窗口时，先保留实际流水并联系管理员核对，不能把它直接套到另一个相同金额订单。

BEpusdt 不提供自动链上退款；退款网络、地址和金额需要单独核对。本站包月权益不会免除机构自身的处理要求。

## 投诉与争议

在支付机构官方后台查看投诉编号和处理要求，依据实际订单、交付与退款记录提交材料。原站的服务商授权和投诉入口不代表本站替你处理投诉。
