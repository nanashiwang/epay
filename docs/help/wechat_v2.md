# 配置微信支付 V2

适用于已经可以使用 APIv2 的微信商户。入口为[支付通道](/user/channels.php) → 微信官方支付 V2；可选 Native 扫码和 H5。

## 准备参数

- 已关联收款商户号的微信 AppID。
- 微信支付商户号。
- 32 位 APIv2 密钥。APIv3 密钥不能替代该字段。
- 对应产品的开通状态及官方要求的域名配置。

## 操作步骤

1. 在[微信支付商户平台](https://pay.weixin.qq.com/)核对商户和产品信息。
2. 在本站添加通道，填入 AppID、商户号、APIv2 密钥。
3. 只选择实际已开通的收款产品，保存配置。
4. 创建测试并付款，等待有效回调；确认测试到账后启用并设为默认。

## V2 与 V3 的区别

本站把二者作为不同接入方式。V3 还需要证书序列号、商户 API 私钥以及微信支付公钥与 ID，见[微信 V3 配置](wechat_v3.md)。编辑已有账号不能直接改变其接入方式；需要新增另一种账号并测试，再切换默认。

当前 V2 自助入口不使用管理员上传的退款证书，也不开放通用退款、代付、JSAPI 或小程序调用。
