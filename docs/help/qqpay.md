# 配置 QQ 钱包

入口：[支付通道](/user/channels.php) → 添加支付通道 → QQ 钱包官方支付。当前支持扫码及 H5 收款。

## 配置流程

1. 准备你自己的 QQ 钱包商户号及 32 位 API 密钥，确认相应产品已经可以使用。
2. 填写易于识别的通道名称、商户号和 API 密钥。
3. 保存后创建小额测试订单，由你在收银台完成付款。
4. 返回本站确认测试到账时间，再启用并设为 QQ 支付默认。
5. 从实际业务网站创建 QQ 支付订单，核对到账和业务通知。

## 状态与维护

账号保存后默认停用。未测试到账不能启用；修改配置需先停用，修改后重新测试。取消默认会停止该方式的新收款，不会转用管理员账户。

不需要填写资金下发操作员或上传退款证书。退款应在自己的支付机构后台处理；不要将资金操作凭据填入普通收款字段。

## 如果使用的是上游网关账户

只有上游提供的易支付商户编号和密钥时，应选择[易支付兼容网关](epay_gateway.md)，支付方式选择 QQ。它与直接配置 QQ 官方商户是两种不同的接入方式。
