# 将业务网站或现成插件接到本站

先完成本站收款通道测试，再配置业务网站。业务网站负责生成订单、保存商品信息和交付商品；本站负责收款处理并发送支付结果。

## 现成易支付插件

1. 在本站商户后台“个人资料 → API信息”取得接口信息。
2. 在业务网站选择与本站协议匹配的易支付插件。
3. 填写本站接口地址、本站商户编号，以及对应版本所需的密钥或 RSA 参数。
4. 选择你已在本站配置并设为默认的支付方式。
5. 保存后从业务网站下单，核对本站订单及业务网站的通知结果。

插件填写的商户编号是本站分配给你的编号，不是支付宝 UID、微信商户号或外部上游网关的 ID。不要把支付机构私钥复制进业务网站的易支付密钥栏。

## 自行开发

本站已有[API 开发文档](/doc/index.html)，优先以它和本站 SDK 为准。旧版入口使用 submit.php / mapi.php，新版接口使用其各自路径及 RSA 签名；不要把原站的 payType、merchantNum 或接口地址混入本站请求。

通用自配通道采用网页、扫码收款，API 下单的 method 使用 web 或 jump。JSAPI、付款码及小程序等方法不在当前通用自助范围内。

## 两个回调地址的用途

- notify_url：供服务器接收支付通知，按[回调验签](callbacks.md)处理。
- return_url：顾客付款后的浏览器返回地址，用于展示结果。

金额、业务订单号和交付状态以你的服务器记录为准。不要在浏览器代码中放密钥，也不要直接依据 return_url 上的参数发货。

## WordPress、Discuz、发卡等程序

先查看该程序当前版本是否提供兼容的易支付插件，再按上面步骤配置。参考资料中的下载包属于原站及其对应版本，不代表本站已验收；本站没有复制或自动安装这些程序。
