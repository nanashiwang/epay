# 配置 USDT / BEpusdt

入口：[USDT 收款](/user/bepusdt.php)。商户自行部署和维护 BEpusdt 网关；本站负责调用网关、验证回调并通知业务网站。不要向本站填写钱包私钥或助记词。

## 准备参数

- 公网 HTTPS 网关地址，端口 443 或 8443，使用有效证书。
- 该实例的 API Token。
- 可选的 TRON 收款地址，以及付款窗口。
- 可使用 USDT 收款的套餐和剩余账号名额。

当前接入固定为人民币订单、USDT / TRC20 付款，不支持把其他链上的转账当作同一笔收款。

## 配置步骤

1. 添加账号名称、网关地址、Token 等参数并保存。
2. 点击“校验接口”。通过表示网关签名回显符合约定，不代表已经收到链上资金。
3. 主动创建 0.10–100 元测试订单，核对收银台的网络、地址和精确币额后自行付款。
4. 等待有效到账回调，核对钱包、网关与本站三处记录。
5. 启用并设为 USDT 默认；再验证业务网站通知。

## 常见状态

出现“待核对”时，不要反复重建同一订单。网关创建超时可能意味着上游已建单；应先核对网关原订单、地址、币额和链上交易号。

多付、少付、错误网络和迟到付款不会因为浏览器显示成功而自动认领。本站没有通用链上退款或强制标付按钮，处理异常时保留凭证并联系管理员。

## 维护

修改 Token 后需要重新校验和测试。历史订单保留原配置快照；停用、归档或套餐到期后仍可确认此前订单。网关本身的扫链健康由商户维护，本站业务通知重试由平台 worker 处理。
