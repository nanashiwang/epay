# 配置 USDT / USDC / BEpusdt

入口：[USDT / USDC 收款](/user/bepusdt.php)。商户自行部署和维护 BEpusdt 网关；本站负责调用网关、验证回调并通知业务网站。不要向本站填写钱包私钥或助记词。

## 准备参数

- 公网 HTTPS 网关地址，端口 443 或 8443，使用有效证书。
- 该实例的 API Token。
- 可选的所选网络收款地址，以及付款窗口。
- 可使用稳定币收款的套餐和剩余账号名额。

订单按人民币计价，使用下面明确支持的币种与网络付款。不能把其他币种或网络的转账当作同一笔收款。

## 币种与网络

| 网络 | USDT | USDC |
| --- | --- | --- |
| TRON / TRC20 | `usdt.trc20` | — |
| Ethereum / ERC20 | `usdt.erc20` | `usdc.erc20` |
| BSC / BEP20 | `usdt.bep20` | `usdc.bep20` |
| Polygon | `usdt.polygon` | `usdc.polygon` |
| Arbitrum One | `usdt.arbitrum` | `usdc.arbitrum` |
| Base | — | `usdc.base` |
| Solana | `usdt.solana` | `usdc.solana` |

每个组合对应一个账号、独立测试和默认路由，各占一个套餐名额。同一实例的 HTTPS 地址和 Token 可复用，保存后不能改币种与网络，需要新增另一组合。网关需配置该网络钱包、扫链服务和实际代币合约；同名代币在不同网络可能是跨链版本，不保证可互换。地址留空使用该网络钱包池，非空时验证 TRON / EVM / Solana 格式。地址格式通过不代表该链实际可收款。


## 配置步骤

1. 选择币种与网络，添加账号名称、网关地址、Token 等参数并保存。
2. 点击“校验接口”。通过表示网关签名回显符合约定，不代表已经收到链上资金。
3. 主动创建 0.10–100 元测试订单，核对收银台的网络、代币合约、地址和精确币额后自行付款。
4. 等待有效到账回调，核对钱包、网关与本站三处记录。
5. 启用并设为该币种与网络的默认账号；再验证业务网站通知。

## 常见状态

出现“待核对”时，不要反复重建同一订单。网关创建超时可能意味着上游已建单；应先核对网关原订单、地址、币额和链上交易号。

多付、少付、错误网络和迟到付款不会因为浏览器显示成功而自动认领。本站没有通用链上退款或强制标付按钮，处理异常时保留凭证并联系管理员。

## 维护

修改 Token 后需要重新校验和测试。历史订单保留原配置快照；停用、归档或套餐到期后仍可确认此前订单。网关本身的扫链健康由商户维护，本站业务通知重试由平台 worker 处理。
