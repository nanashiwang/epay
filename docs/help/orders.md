# 订单、流水与通知记录怎么看

在[支付通道](/user/channels.php)可查看通用自配通道的支付订单、通知和操作记录。支付宝收款码与 BEpusdt 保留各自的专项记录入口；商户订单总览仍在“订单记录”。

## 先对照订单标识

| 标识 | 用途 |
| --- | --- |
| 业务订单号 | 你的业务网站创建的订单编号 |
| 本站订单号 | 本站用于查单、通知和售后定位的编号 |
| 支付流水号 | 支付机构或上游网关确认的交易编号 |
| 链上交易号 | BEpusdt 对应的链上转账凭证 |

排查问题时尽量提供本站订单号、发生时间和报错文字，不发送私钥、API 密钥或完整签名请求。

## 三类记录

“支付订单”关注是否到账以及金额和流水。“通知记录”关注业务网站是否收到结果。“操作记录”关注账号保存、启停、默认切换及到账确认等动作。

测试订单可能没有发给你的业务网站的通知，因为它不是业务网站发起的商品订单。验收业务通知需要另外从业务网站下单。

## 支付宝原生码流水

原生码页面还能看到已匹配、未匹配、金额歧义和超出自动确认窗口等收入状态。写入核对说明只保存处理依据，不会把没有符合凭证的订单强制改为成功。

## 配置归档后

归档释放账号名额并从当前账号列表移除配置，保留历史记录与在途订单确认。请先停用并取消默认；同一支付方式需要继续收款时，先准备好另一个已测试账号。

## 参考来源

[支付FM：商户订单](https://docs.zhifux.com/read/zhifufm/morder)。原站的手工确认和差额补单按钮不属于本站通用自助流程。

## 支付异常核对

在商户侧栏打开“支付异常核对”，按平台订单号查看未确认订单、最近通知及核对历史。填写原因和凭证可保留处理依据；已付款但通知失败可重试通知。BEpusdt 已有网关单号时可查单核对，付款确认仍需原始签名回调。未知结果请先核对网关，不要重复创建订单。
